# КП-студия

Локальная программа для менеджера небольшой студии: таблица клиентов → персональные предложения → PDF и журнал. Обязательный интерфейс командной строки уже существует; браузерный экран — оболочка над тем же конвейером.

Вход: CSV или XLSX с компанией, контактом, потребностями и бюджетом. Выход: PDF по компаниям, исходный текст, отчёт запуска. Демо явно отделяется от платной генерации через ProxyAPI. Ошибки не подменяются успешным результатом. Пользователь проверяет предложения перед отправкой. Ключи никогда не отображаются в интерфейсе.

Визуальная основа уже задана examples/Образец КП.pdf: белая бумага, тёмный сине-зелёный текст, спокойный зелёный акцент. Экран наследует эту систему. Основная среда — рабочий стол Windows, с адаптацией для узкого окна. Запуск только на loopback-интерфейсе.
