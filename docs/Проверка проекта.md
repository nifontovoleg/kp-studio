# Проверка КП студии 19 октября 2026 года

## Результат

Локальный конвейер, браузерный экран, PDF, журнал, тесты и Docker проверены. Интеграция ProxyAPI реализована, однако успешная генерация AI не подтверждена из-за недоступного сетевого соединения. До учебной приёмки необходимо выполнить успешный реальный запрос.

## Автоматические проверки

24 теста прошли. Проверены некорректные бюджеты, совпадение CSV и XLSX, безопасные имена папок, продолжение после обычной ошибки клиента, повторные запуски, накопление журнала, отклонение пустого и оборванного AI-ответа, сохранение текста при сбое PDF. Для системных ошибок провайдера проверено прекращение дальнейших запросов, сохранение предшествующего успешного PDF и запись оставшихся строк как не отправленных. HTTP-тесты проверяют загрузку таблицы, генерацию, скачивание PDF, журнал, запрет постороннего Origin/Host и произвольных путей.

Команда: `.\.venv\Scripts\python.exe -m pytest -q --basetemp .tmp\pytest-unrestricted`. Последний результат: `24 passed in 4.60s`. Автоматические тесты выполняются без платных запросов.

## Браузер и демонстрация

Реальный Chromium прошёл сценарий: старт → пример CSV → три PDF → скачивание PDF и журнала → загрузка Excel → проверка ошибочного бюджета → частичный результат. Отдельно проверен экран 390 × 844 без горизонтального переполнения всей страницы. Широкая таблица прокручивается внутри своего контейнера. Ошибок JavaScript и неудачных сетевых запросов в демосценарии не было. JSON-отчёт находится в demo/browser-check.json. Записан WebM-скринкаст, сохранены скриншоты и демонстрационный PDF. Данные компаний вымышлены, режим демонстрации подписан.

Независимое завершающее ревью интерфейса и кода завершилось вердиктом ship для локальной версии. Замечания по русскому сообщению бюджета и покрытию fail-fast устранены и повторно проверены ревьюером.

## PDF и техническое задание

Windows PDF растеризован и осмотрен; кириллица также проверена извлечением текста. Одна страница A4, обрезаний и наложений не обнаружено. Образцы находятся в examples/Образец КП.pdf и demo/Демонстрационное предложение.pdf.

ТЗ подготовлено в Markdown и DOCX. Исправленный DOCX экспортирован в PDF через установленный Word, обе страницы растеризованы и визуально проверены. Линия под заголовком удалена. Промежуточные файлы проверки в публичную поставку не включены.

## Docker

Docker Desktop запущен, версия Engine 29.8.2. Образ kp-studio:local успешно собран. `docker run --rm kp-studio:local` создал три PDF без ошибок. Повторный запуск с bind-mount папки output сохранил PDF, TXT и журнал на компьютере. `docker compose config --quiet` завершился успешно. Контейнер работает от непривилегированного пользователя, кириллицу обеспечивает DejaVu. .env, локальное окружение и output исключены из build-контекста.

## Реальный ProxyAPI

Выполнены попытки для одной вымышленной компании через CLI и браузер. Успешного AI-ответа нет. DNS системного резолвера и Cloudflare совпадает; подключение к api.proxyapi.ru:443 завершается по таймауту. Проверка TCP из Docker дала тот же результат. Официальный альтернативный адрес также не ответил. Ключ в чат, скриншоты, репозиторий и архив не включался.

Фактический экран сохранён в demo/07-live-api.png, итог — в demo/live-check.json. Интерфейс показывает «Предложения не созданы», журнал содержит ошибку, локальный шаблон автоматически вместо AI не используется. Баланс и права ключа не проверены, поскольку соединение не дошло до API.

## Комплект и следующий шаг

Код, README, шаблоны таблиц, ТЗ, PDF, скриншоты и скринкаст подготовлены для репозитория https://github.com/nifontovoleg/kp-studio. Архив для передачи создаётся tools/package_project.py; он проверяет состав файлов, отсутствие текущего ключа и целостность ZIP. .env, output, .venv и временные файлы исключены.

После восстановления сетевого доступа нужно выполнить `.\.venv\Scripts\python.exe -m studio examples\clients.xlsx --limit 1`, проверить персонализацию PDF и записать успешную AI-демонстрацию. Только после этого прикреплять проект в раздел «Проект №1» тетради карьерных действий и отправлять на проверку. Отправка тетради, сообщения менеджеру и размещение на маркетплейсе не выполнялись.
