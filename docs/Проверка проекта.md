# Проверка КП студии 19 октября 2026 года

## Результат

Локальный конвейер, браузерный экран, PDF, журнал, тесты и Docker проверены. Интеграция ProxyAPI реализована; сеть до api.proxyapi.ru теперь доступна, но успешная генерация AI не подтверждена: текущий ключ отклонён (HTTP 401). До учебной приёмки необходимо заменить ключ и выполнить успешный реальный запрос.

## Автоматические проверки

30 тестов прошли. Проверены некорректные бюджеты, совпадение CSV и XLSX, безопасные имена папок, продолжение после обычной ошибки клиента, повторные запуски, накопление журнала, отклонение пустого и оборванного AI-ответа, один повтор при таймауте, HTTP 429 и 5xx и отказ без повтора при HTTP 401/402 (на поддельном клиенте), сохранение текста при сбое PDF. Для системных ошибок провайдера проверено прекращение дальнейших запросов, сохранение предшествующего успешного PDF и запись оставшихся строк как не отправленных. HTTP-тесты проверяют загрузку таблицы, генерацию, скачивание PDF, журнал, запрет постороннего Origin/Host и произвольных путей.

Команда: `.\.venv\Scripts\python.exe -m pytest -q --basetemp .tmp\pytest-unrestricted`. Последний результат (Linux): `30 passed in 2.6s`. Автоматические тесты выполняются без платных запросов.

## Браузер и демонстрация

Реальный Chromium прошёл сценарий: старт → пример CSV → три PDF → скачивание PDF и журнала → загрузка Excel → проверка ошибочного бюджета → частичный результат. Отдельно проверен экран 390 × 844 без горизонтального переполнения всей страницы. Широкая таблица прокручивается внутри своего контейнера. Ошибок JavaScript и неудачных сетевых запросов в демосценарии не было. JSON-отчёт находится в demo/browser-check.json. Записан WebM-скринкаст, сохранены скриншоты и демонстрационный PDF. Данные компаний вымышлены, режим демонстрации подписан.

Независимое завершающее ревью интерфейса и кода завершилось вердиктом ship для локальной версии. Замечания по русскому сообщению бюджета и покрытию fail-fast устранены и повторно проверены ревьюером.

## Реальный ProxyAPI

Ранее (утро 19.10.2026) подключение к api.proxyapi.ru:443 завершалось по таймауту — см. demo/07-live-api.png. Повторная проверка 19.10.2026 в 13:35 (UTC+5): эндпоинт `https://api.proxyapi.ru/v1` отвечает за 3–5 секунд, по документации ProxyAPI адрес и идентификатор модели `openai/gpt-5-mini` верны. Запрос `--limit 1` получил HTTP 401 «Invalid API Key»: имеющийся ключ недействителен или отозван. Итог — в demo/live-check.json. Ключ в репозиторий, журнал и архив не включался.

Только после этого прикреплять проект в раздел «Проект №1» тетради карьерных действий и отправлять на проверку. Отправка тетради, сообщения менеджеру и размещение на маркетплейсе не выполнялись.
