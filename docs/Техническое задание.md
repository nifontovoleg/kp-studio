# Техническое задание на КП студию

## Назначение

КП-студия создаёт персонализированные коммерческие предложения по таблице клиентов. Пользователь получает отдельный PDF для каждой компании и журнал обработки. Проект выполняется по учебному заданию «AI-генератор коммерческих предложений».

## Аудитория и задача

Менеджеры небольших студий и агентств, которые готовят предложения по входящим запросам. Повторный ручной перенос данных и оформление документов занимают время; программа автоматизирует подготовку черновиков. Измеримые обещания экономии времени и роста продаж в проект не входят.

## Обязательные функции и приёмка

1. Прочитать CSV в UTF-8 и Excel XLSX. Поля: название компании, контактное лицо, потребности клиента, бюджет в рублях. Проверка: одинаковые таблицы в двух форматах дают одинаковые данные клиентов.
2. Создать персональный текст через модель OpenAI с помощью библиотеки openai. В локальной поставке доступ осуществляется через ProxyAPI. Проверка: реальный запрос на вымышленных данных завершается и даёт текст по задаче клиента. Если для сдачи требуется именно прямой OpenAI API, адрес и ключ переключаются в .env.
3. Сформировать PDF с кириллицей и оформлением. Документ содержит компанию, контакт, потребности, AI-текст, бюджет, условия согласования и следующий шаг. Проверка: файл открывается, текст читается, нет обрезанных строк и наложений.
4. Сохранить результаты в отдельную папку компании. Повторный запуск и повтор компании не перезаписывают предыдущие документы. Проверка: два запуска сохраняют оба набора PDF.
5. Записать результат каждой строки в journal.jsonl с временем, идентификатором запуска, статусом и путями файлов или ошибкой. Проверка: ошибка одной строки не прерывает остальные, журнал сохраняется между запусками.

## Дополнительные функции

Проверка таблицы без расходов; ограничение количества клиентов; локальная демонстрация с явной маркировкой без AI; сохранение ответа в TXT перед созданием PDF; сводный JSON каждого запуска; команды PowerShell и запуск CMD; Docker Compose. Локальный браузерный экран позволяет выбрать таблицу, проверить строки, запустить генерацию и скачать PDF с журналом.

## Технологии

Python 3.12+, pandas, openpyxl, openai, reportlab, python-dotenv. Тесты pytest. Командная строка и локальный браузерный экран на стандартном http.server используют один конвейер. Сервер слушает только 127.0.0.1 и не предназначен для публичного размещения. Контейнер — дополнительный способ запуска командной строки. Работа локальная, без регистрации и базы данных.

## Ограничения и риски

До 100 строк за запуск. Название и контакт до 200 символов, потребности до 6000 символов. Положительный бюджет до 1 млрд рублей. Файлы .xls не поддерживаются. Выполняется один запуск за раз. При сетевом сбое требуется повторный запуск выбранных строк; автоматического возобновления нет. Текст AI проверяет пользователь, программа не рассчитывает окончательную цену и сроки. Бюджет разработки учебный; расходы на API оплачивает владелец ключа, размер зависит от модели и числа запросов. Расчёт стоимости запросов в интерфейсе не предусмотрен. При таймауте, HTTP 429 и 5xx выполняется один автоматический повтор; ошибки ключа и баланса не повторяются.

Ключ хранится только в локальном .env, исключённом из Git. В API передаются только данные выбранной строки. В демонстрации используются вымышленные компании. Рабочие документы, TXT и журнал содержат клиентские данные и требуют защищённого хранения. Отправка писем и публикация документов не выполняются программой.
